# B2-FC: 三旋翼 VTOL 飞控底层算法

## 📌 项目简介
本项目为独立设计的三旋翼倾转旋翼（VTOL）飞控系统的核心控制律与状态机代码。项目采用纯 C99 编写，实现了多旋翼悬停、倾转过渡、纯固定翼平飞的完整闭环控制，并具备完善的防炸机安全补丁与物理仿真验证。

## 🛠️ 技术栈与工程架构
*   **语言**: 纯 C (C99)
*   **核心架构**: 高度/姿态串级 PID + 动态 B 矩阵混控 + 飞行模式状态机
*   **工程特性**: 
    *   严格的防除零 (fmaxf) 与物理限幅 (sat) 保护。
    *   积分分离与抗积分饱和 (Anti-Windup) 机制。
    *   无扰切换 (Bumpless Transfer)：模式切换瞬间清空积分，防止姿态突变。
    *   平滑权重交接：倾转过渡阶段旋翼与气动舵面的动态权重分配。

## 📂 目录结构
*   `main.c`: 飞控主循环与物理仿真引擎。
*   `flight_ctrl`: 串级 PID 与姿态/高度控制律实现。
*   `mixer_transition`: 多旋翼/过渡/固定翼混控解算矩阵。
*   `flight_manager`: 飞行状态机与遥控目标生成。
*   `utils`: 基础数学工具 (限幅、死区等)。
